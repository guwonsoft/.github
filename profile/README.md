### 💡 About Us

구원소프트는 견고한 엔지니어링 문화와 사용자 중심의 사고를 바탕으로 웹 서비스와 솔루션을 설계·구축합니다.  
빠른 프로토타이핑부터 안정적인 대규모 분산 아키텍처까지, 비즈니스 목표를 실현하는 최적의 기술 솔루션을 제공합니다.

- 🌐 **Web Architecture**: 최신 웹 표준과 반응형 생태계를 선도하는 풀스택 웹 솔루션
- ⚡ **High Performance & Stability**: 체계적인 CI/CD 및 자동화된 검증 파이프라인 기반의 안정적인 시스템 구축
- 🤝 **Collaborative Culture**: 문서화 중심의 설계, TDD, 코드 리뷰를 통한 지속 가능한 소프트웨어 개발

### 🤝 How We Work

1. **Keep It Simple & Robust**: 불필요한 복잡성을 배제하고 본질에 집중한 단순하고 견고한 아키텍처를 추구합니다.
2. **Automated Verification**: Lint, Type-Check, Test가 통합된 빌드 파이프라인을 통과한 안정적인 코드만 프로덕션에 배포합니다.
3. **Agile & Feedback**: 짧은 스프린트와 명확한 피드백 루프로 프로덕트를 빠르게 고도화합니다.
